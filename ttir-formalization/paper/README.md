# TTIR-to-TTAdapter paper

`main.tex` is an anonymous research-paper draft in the LIPIcs format used by ECOOP 2026. `main.pdf` is generated by `make`. `references.bib` contains the cited literature.

## Format and status

The official ECOOP 2026 technical-paper call specifies LIPIcs proceedings formatting, double-anonymous review, no initial submission page limit, and a maximum of 25 camera-ready pages excluding references. These requirements were checked on 2026-11-03 at:

https://2026.ecoop.org/track/ecoop-2026-technical-papers

The draft uses `lipics-v2021` with A4 paper, US English, and anonymous metadata. It preserves the class's fonts, margins, and section styles. `hideLIPIcs` suppresses publication metadata rather than inventing a DOI, article number, or acceptance information. This is a format-compatible draft, not an accepted ECOOP article or a claim of submission eligibility; ECOOP 2026 took place June 29–July 3, 2026.

Author identities are intentionally omitted. Confirm authorship and affiliations before producing an attributed version. An explicit generative-AI disclosure is included for author review, consistent with the need to disclose substantive AI assistance.

## Build

Run `make` in this folder. The folder bundles an unchanged copy of the repository's existing `lipics-v2021.cls`, retaining its license notice. The paper can be compiled independently of the neighboring manuscript. Required programs are `latexmk`, `pdflatex`, and BibTeX plus the packages required by the class, `booktabs`, and `stmaryrd`.

Run `make proofs` to rebuild the Lean development and print the principal theorem assumptions. `make clean` removes intermediate LaTeX files while retaining the PDF.

## Claim boundaries

The manuscript describes the existing rank-one i32 model without adding proof claims. It distinguishes intrinsic shape indexing from real compiler type preservation, exact bit-vector results from a missing general signed-decoding bridge, and arbitrary initial contents from poison or per-allocation nondeterminism. Broadcast, the actual C++ implementation, and the full pipeline are not verified.

The source checkout is pinned by revision and file/line anchors in the paper and `../FINDINGS.md`; no public source archive or artifact DOI is invented. The related-work bibliography uses verified title/DOI metadata. Before submission, authors must independently review the manuscript, the completeness of related work, and the correspondence to the intended source checkout.
